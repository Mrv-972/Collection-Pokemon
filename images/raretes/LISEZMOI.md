# Icônes de rareté (TCG Pocket)

Les quatre symboles du jeu, repris de
[flibustier/pokemon-tcg-exchange](https://github.com/flibustier/pokemon-tcg-exchange)
(`public/images/rarity/`), projet sous licence AGPL-3.0.

| Fichier | Ce que c'est | Raretés concernées |
|---|---|---|
| `losange.png` | le losange gris | Un à Quatre Diamants (répété 1 à 4 fois) |
| `etoile.png` | l'étoile dorée | Une à Trois Étoiles |
| `couronne.png` | la couronne | Couronne |
| `chromatique.png` | l'éclat multicolore | Chromatique, Chromatique deux étoiles |

Le système du jeu répète le même symbole : trois losanges pour « Trois
Diamants ». Le code fait de même plutôt que d'avoir un fichier par
combinaison.

Ces visuels appartiennent en dernier ressort à Nintendo / Creatures / GAME
FREAK, comme les illustrations de cartes déjà présentes dans `images/cards/`.

Le jeu physique n'utilise pas ces icônes : ses quarante raretés
(« Illustration spéciale rare », « Holo Rare VSTAR »…) gardent les symboles
typographiques.
